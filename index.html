Как подключить

Задача → план → правки → pull request

Опишите задачу голосом — с телефона.

VoiceIDE отдаёт агенту задачу, следит за его работой и показывает результат по файлам. Всё, что попадёт в репозиторий, вы подтверждаете сами.

Получить доступ Смотреть скриншоты
  • Android 8.0+
  • диктовка офлайн
  • агент на своём сервере
  • PR только с подтверждением

Сценарий

Пять шагов от фразы до pull request

Ничего не публикуется само: агент работает в отдельной рабочей копии, а решение по каждому файлу принимаете вы.

  1. 01

    Подключите GitHub

    OAuth Device Flow, затем выбор публичного или приватного репозитория размером до 500 МБ.

  2. 02

    Опишите задачу

    Голосом на русском или английском либо текстом. Выберите модель агента и режим хода: план или сборка.

  3. 03

    Следите за работой

    Очередь, рабочая копия и отдельное рабочее пространство на задачу. В журнале видно инструменты, команды и пути.

  4. 04

    Проверьте изменения

    Diff по файлам: принять файл, попросить агента о правке или оставить заметку. Правки идут в ту же сессию.

  5. 05

    Опубликуйте PR

    Заголовок, описание и явное подтверждение. Worker создаёт ветку и pull request; слияние — только ваше.

voiceide · itmagelab/VoiceIDE 
$ voiceide task new --dictate
✓ распознано: «добавь экран настроек сервера»

$ voiceide task run --mode plan
✓ план готов · 3 файла · 2 проверки

$ voiceide task run --mode build
✓ сборка завершена · +128 −14

$ voiceide review --accept-all
✓ все файлы приняты

$ voiceide pr create
✓ pull request #42 → master
$ voiceide task new --dictate
✓ heard: "add a server settings screen"

$ voiceide task run --mode plan
✓ plan ready · 3 files · 2 checks

$ voiceide task run --mode build
✓ build finished · +128 −14

$ voiceide review --accept-all
✓ all files accepted

$ voiceide pr create
✓ pull request #42 → master

Так выглядит цикл задачи: план и сборка — два разных агента с разными инструментами.

Возможности

Всё, что нужно, чтобы не садиться за компьютер

Приложение управляет агентом и показывает его работу. Код, коммиты и pull request остаются в вашем репозитории и под вашим аккаунтом.

●

Диктовка задач

Надиктуйте новую задачу, уточнение, комментарий к PR или заметку к файлу. Текст распознавания редактируется перед отправкой.

●

Речь без сети

Системный сервис устройства либо локальные модели Whisper Tiny и Parakeet v3. Аудио не сохраняется и не уходит в сеть.

●

Режим плана

План-агент изучает репозиторий без инструментов записи. Обсудите план голосом, а сборку запустите одним тапом.

●

Модель на задачу

Каталог провайдеров и моделей приходит с сервера. Выбор сохраняется в задаче и действует на все её ходы.

●

Журнал выполнения

Таймлайн действий агента, использованные инструменты, команды и затронутые пути. Секреты маскируются.

●

Ревью по файлам

Принять файл, попросить правки, оставить заметку. «Принять все» можно отменить, а решения — изменить.

●

Работа в одной сессии

Замечания возвращаются агенту в тот же воркспейс: контекст обсуждения плана и правок сохраняется между ходами.

●

PR без сюрпризов

Публикация только после вашего подтверждения, в отдельную ветку. Автоматического слияния нет.

Запуск

Демо-сервер или свой

При первом старте приложение предлагает два пути: общий демо-инстанс или сервер, который вы подняли сами.

Публичный демо-сервер

Готовый общий инстанс, чтобы попробовать сценарий сразу. Подходит, чтобы оценить приложение без своей инфраструктуры.

Написать автору

Свой сервер

Весь стек в одном Compose-файле: API, worker, Runtime агента и PostgreSQL. Нужен домен с DNS на ваш сервер и открытые порты 80/443.

git clone git@github.com:itmagelab/VoiceIDE.git
cd VoiceIDE
cp .env.example .env      # ключи и пароли
podman compose up --detach

Локально API доступен на http://127.0.0.1:8080, снаружи — через Caddy с HTTPS.

Что нужно

  • Android 8.0 (API 26) или новее — современный смартфон с микрофоном.
  • arm64-v8a — APK под другие ABI собираются отдельно.
  • Аккаунт GitHub — чтобы подключить репозиторий.
  • Ключ LLM-провайдера — если поднимаете свой сервер.

Сборки лежат в закрытом репозитории: напишите автору, и вы получите ссылку на APK нужной архитектуры. Актуальная версия — v0.9.1.

Доверие

Приватность по умолчанию

Токены зашифрованы

OAuth-токены GitHub хранятся в PostgreSQL в виде AES-256-GCM. Отключение GitHub удаляет токен из VoiceIDE.

Аудио не хранится

Диктовка не сохраняет записи и историю фраз. Локальные модели распознают речь прямо на устройстве.

Ничего не публикуется молча

Изменения остаются в рабочем пространстве, пока вы явно не подтвердите создание pull request.

Секреты маскируются

В журнале выполнения значения маскируются; содержимое файлов и внутренние рассуждения модели не сохраняются.

Агент в песочнице

Runtime ограничен списком команд, а операции GitHub выполняет worker вне контейнера агента.

Ваш аккаунт

Коммиты, ветки и pull request создаются от имени подключённого GitHub-аккаунта и только вашего репозитория.
