# Сайт VoiceIDE

> 🌐 **Основной сайт приложения:** [voiceide.ru](https://voiceide.ru/)

Статическая визитка проекта для GitHub Pages. Без сборки и зависимостей: чистые
HTML, CSS и JavaScript, все тексты переключаются между RU и EN прямо в браузере.

## Структура

```
VoiceIDE.ru/
├── index.html            # разметка всех секций и SEO-метатеги
├── robots.txt            # правила обхода для поисковых роботов
├── sitemap.xml           # карта сайта вместе с изображениями
├── .nojekyll             # чтобы Pages не прогонял Jekyll
├── assets/
│   ├── style.css         # светлая тема gruvbox
│   ├── main.js           # словари RU/EN и поведение страницы
│   └── img/              # иконка и скриншоты приложения
└── tools/
    └── make-og-image.swift # генератор превью og-image.png
```

Скриншоты скопированы из `docs/release-assets/`, чтобы сайт собирался из одной
папки: workflow публикует только `VoiceIDE.ru/`. Имена совпадают с исходными:
`01-tasks`, `02-new-task`, `03-dictation`, `04-agent-working`, `05-review-diff`,
`06-pull-request`. После обновления скриншотов в основном репозитории их нужно
перекопировать сюда и поправить ссылки в `index.html`, `assets/main.js`
(подписи `alt.*` и `screens.*.text`) и `sitemap.xml`.

## Превью для соцсетей

`assets/img/og-image.png` — обложка 1200×630, которую видно в ссылке на сайт.
Собирается из тех же скриншотов скриптом на CoreGraphics (только macOS, без
зависимостей):

```sh
swift tools/make-og-image.swift assets/img
```

Скрипт рисует первый экран сайта: текст слева, три телефона со скриншотами
приложения справа. После замены скриншотов перегенерировать и обложку.

## Публикация

Workflow [`.github/workflows/pages.yml`](../.github/workflows/pages.yml)
собирает и публикует папку при пуше в `master`, если изменились файлы сайта.
Дополнительно: **Settings → Pages → Source → GitHub Actions**.

Адрес проекта: <https://itmagelab.github.io/VoiceIDE/>

### Важно: закрытый репозиторий

Pages для приватного репозитория доступны только на платных планах GitHub
(Pro, Team, Enterprise). Если тарифа нет, есть два пути:

1. Вынести папку `VoiceIDE.ru` в отдельный публичный репозиторий
   (например, `itmagelab/VoiceIDE.ru`) и положить туда же workflow — он
   работает без изменений, если заменить `path` на `.`.
2. Оставить сайт в закрытом репозитории и публиковать из рабочей копии
   (`git subtree split` или ручная загрузка через `gh api`).

### Свой домен

Файл `CNAME` публикует основной домен `voiceide.ru`. В DNS настройте записи
GitHub Pages для apex-домена и включите HTTPS в `Settings → Pages`. Для
перенаправления `www.voiceide.ru` настройте DNS и редирект на стороне DNS-
провайдера или хостинга.

## Правка текстов

Все подписи лежат в `assets/main.js` в объектах `I18N.ru` и `I18N.en`. В разметке
элементы помечены атрибутами:

- `data-i18n="ключ"` — заменяет текст элемента;
- `data-i18n-alt="ключ"` — подпись `alt` у изображений;
- `data-i18n-content="ключ"` — атрибут `content` у метатегов (`og:image:alt`);
- `data-i18n-attr="aria-label:ключ"` — произвольный атрибут;
- `data-lang-block="ru"` / `data-lang-block="en"` — блоки, видимые только на
  одном языке (так сделаны терминальные примеры).

Номер версии в подвале и в блоке «Актуальная версия» меняется в `index.html` и
в `assets/main.js` (`install.note.b`).

## Контакты

Раздел «Контакты» (`#contacts` в `index.html`) содержит три карточки: Телеграм,
почту и телефон. Готовый текст продублирован в `assets/main.js` в ключах
`contacts.*`, а ссылки (`https://t.me/…`, `mailto:`, `tel:`) заданы прямо в
разметке. Меняя адрес или номер, поправьте и разметку, и словари RU/EN.

Те же данные попадают в микроразметку: у `Organization` в JSON-LD есть
`contactPoint` (email, телефон) и `sameAs` со ссылкой на Телеграм, а ответ
`faq.6.a` совпадает с `FAQPage`. Эти блоки нужно держать синхронными.

## Ссылки в подвале

В колонке «Проект» осталась только ссылка на репозиторий проекта. Ссылки на
внутренние документы (`README`, `DEVELOPMENT.md`, документация) убраны: они
работают только для участников приватного репозитория.

## Индексация и SEO

Сайт уже подготовлен к индексации. Что где лежит и что обновлять:

- `robots.txt` — сайт открыт для обхода, указан адрес `sitemap.xml`;
- `sitemap.xml` — карта сайта с датой обновления (`lastmod`) и списком
  скриншотов в формате image sitemap. **При изменении текстов или картинок
  поправьте `lastmod`** на дату публикации;
- `index.html`, `<head>` — заголовок страницы, описание, `canonical`, `robots`
  (`max-image-preview:large`), Open Graph и Twitter-карточки, иконка и
  `apple-touch-icon`;
- микроразметка JSON-LD (`@graph`) описывает сайт (`WebSite`), страницу
  (`WebPage`), организацию (`Organization`), приложение
  (`SoftwareApplication`: категория, версия, скриншоты, список возможностей,
  ссылка на скачивание) и блок вопросов (`FAQPage`);
- секция «Частые вопросы» (`#faq`) даёт текстовое содержимое под запросы и
  одновременно служит источником для `FAQPage`. Вопросы и ответы должны
  совпадать с разметкой JSON-LD — так требует Google;
- при переключении языка `assets/main.js` обновляет `<html lang>`, заголовок
  вкладки, `meta description`, `og:*` и `twitter:*`.

Что стоит сделать позже (вне этого сайта):

1. Добавить в GitHub-репозиторий ссылку на <https://voiceide.ru/> в описании и
   в разделе «Website», чтобы поисковики видели связь.
2. Зарегистрировать сайт в Google Search Console и Яндекс.Вебмастере и отправить
   `sitemap.xml` — это ускоряет появление страницы в поиске.
3. Отдельная англоязычная версия (`/en/`) со своим адресом, если понадобится
   продвижение на английском: сейчас оба языка живут по одному адресу, поэтому
   `hreflang` не используется.
