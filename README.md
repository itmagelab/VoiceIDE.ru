# Сайт VoiceIDE

> 🌐 **Основной сайт приложения:** [voiceide.ru](https://voiceide.ru/)

Статическая визитка проекта для GitHub Pages. Без сборки и зависимостей: чистые
HTML, CSS и JavaScript, все тексты переключаются между RU и EN прямо в браузере.

## Структура

```
VoiceIDE.ru/
├── index.html            # разметка всех секций
├── .nojekyll             # чтобы Pages не прогонял Jekyll
└── assets/
    ├── style.css         # светлая тема gruvbox
    ├── main.js           # словари RU/EN и поведение страницы
    └── img/              # иконка и скриншоты приложения
```

Скриншоты скопированы из `docs/release-assets/`, чтобы сайт собирался из одной
папки: workflow публикует только `VoiceIDE.ru/`.

## Публикация

Workflow [`.github/workflows/pages.yml`](../.github/workflows/pages.yml)
собирает и публикует папку при пуше в `master`, если изменились файлы сайта.
Дополнительно: **Settings → Pages → Source → GitHub Actions**.

Адрес проекта: <https://itmagelab.github.io/VoiceIDE/>

### Важно: закрытый репозиторий

Pages для приватного репозитория доступны только на платных планах GitHub
(Pro, Team, Enterprise). Если тарифа нет, есть два пути:

1. Вынести папку `VoiceIDE.ru` в отдельный публичный репозиторий
   (например, `itmagelab/VoiceIDE.ru`) и положить туда же workflow — он
   работает без изменений, если заменить `path` на `.`.
2. Оставить сайт в закрытом репозитории и публиковать из рабочей копии
   (`git subtree split` или ручная загрузка через `gh api`).

### Свой домен

Файл `CNAME` публикует основной домен `voiceide.ru`. В DNS настройте записи
GitHub Pages для apex-домена и включите HTTPS в `Settings → Pages`. Для
перенаправления `www.voiceide.ru` настройте DNS и редирект на стороне DNS-
провайдера или хостинга.

## Правка текстов

Все подписи лежат в `assets/main.js` в объектах `I18N.ru` и `I18N.en`. В разметке
элементы помечены атрибутами:

- `data-i18n="ключ"` — заменяет текст элемента;
- `data-i18n-alt="ключ"` — подпись `alt` у изображений;
- `data-i18n-attr="aria-label:ключ"` — произвольный атрибут;
- `data-lang-block="ru"` / `data-lang-block="en"` — блоки, видимые только на
  одном языке (так сделаны терминальные примеры).

Номер версии в подвале и в блоке «Актуальная версия» меняется в `index.html` и
в `assets/main.js` (`install.note.b`).
